P7: AI-Assisted Crop Type and Cropping Pattern Mapping using Multi-Season Satellite Data
Overview

This project demonstrates crop type and cropping pattern mapping using multi-season Sentinel-2 satellite imagery and Google Earth Engine (GEE).

The workflow integrates Remote Sensing, GIS, Vegetation Index Analysis, and Machine Learning techniques to identify agricultural patterns within Medak District, Telangana, India.
